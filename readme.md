# Speed Test CLI (Python)

Консольный скрипт для замера скорости скачивания файла по указанному URL.

## Требования
* Python 3.8+
* Установленная библиотека `requests`:
  ```bash
  pip install requests

Как запустить

    Клонируйте репозиторий.

    Установите зависимости: pip install -r requirements.txt (или просто pip install requests).

    Запустите скрипт, передав URL в качестве аргумента:
    bash

python speed_test.py https://google.com

Единицы измерения

    Время: секунды (сек).

    Объём: Мегабайты (МБ). Расчет: 1 МБ = 1024 * 1024 байт.

    Скорость: Мегабиты в секунду (Мбит/с / Mbps). Расчет: (Всего байт * 8) / (Общее время в секундах * 1024 * 1024).

Как остановить

Скрипт выполняется последовательно 10 раз и завершает работу автоматически.
